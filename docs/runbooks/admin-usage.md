## Features Overview
- Portfolio: Create, edit, delete, reorder projects
- Experience: Manage job entries
- Education: Track academic history
- Skills: Organize skills by group and order
- Certificates: Manage certifications
- Recommendations: Curate testimonials
- Blogs: Rich text editor with publishing controls
- Services: Manage service offerings
- Media: Upload and manage assets
- Contact: View contact submissions
- Settings: Theme selection, maintenance mode, profile

---

## Tips & Best Practices
- Use drag-and-drop (where available) to adjust display order
- Keep drafts unpublished until ready; use previews where supported
- Perform content changes in small batches to simplify reviews

---

## Troubleshooting
- Cannot login
  - Ensure database seeded; reset password via reseed if necessary
- Layout or theme not updating
  - Save settings and refresh; ensure theme registry entry is valid
