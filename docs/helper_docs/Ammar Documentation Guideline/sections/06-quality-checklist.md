# 6. Quality Checklist

- [ ] Intro file name shows current version
- [ ] TOC links match section files and resolve correctly
- [ ] Section files are focused and free of duplicate metadata
- [ ] Headers, dates, changelog updated where edited
- [ ] Line width ≤120 chars (except code blocks when needed)
- [ ] Examples, diagrams, links render correctly
- [ ] Code blocks have language specified
- [ ] Archived content referenced when relevant
- [ ] No trailing spaces or inconsistent formatting
