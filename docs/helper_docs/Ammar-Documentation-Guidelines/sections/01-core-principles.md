# 1. Core Principles

## Concise Yet Comprehensive
Documentation must be **concise but complete**—eliminate filler while keeping all context needed for understanding. Every sentence should earn its place.

## Key Principles
- Keep documentation consistent, compact, and discoverable across projects.
- Lead with the "why" before diving into "how"—context clarifies actions.
- Optimize for skim readers and AI: short sentences, direct verbs, zero filler.
- Treat docs as living assets: update when reality changes.
- Write in active voice with clear, professional English.
- Front-load critical information before deep details.
- One topic per file—link instead of duplicating.
- Include examples, edge cases, and implications—but trim explanations ruthlessly.
